Курсовая работа
Описание:
В работе выполнена создании вэб приложения для формирования у пользоватея какой либо устойчивой привычки через сообщения
бота реализованного бота в месенджере телеграмм. Пользователь создат модель привычки которуу желает сформировать, 
определяет периодичность ее выполнения для формирования. Созданные пользователем определяются им как приватные (срытые)
доступные только хозяину привычки или сделать ее публичной, тогда ее будут видеть все. За выполненное действие 
(привычки) пользователь может выбрать либо вознаграждение, либо приятную привычку (приятное действие). За адекватную 
работу и формирование модели привычки организована валидация модели привычки.

Установка:
Клонируйте репозиторий ''' git clone '''.
Установите зависимости: ''' pip install -r requirements.txt '''
Запуск из модуля main.py
Тестирование:
Выполнено частичное тестирование модулем pytest, на боллее чем 75% из условия курсовой работы, так же выполнено логирование всех функций проекта с возможностью отслеживания в лог файлах работы функций их переменных и дата фреймов используемых и образуемых во время работы функций.
